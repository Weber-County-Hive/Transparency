How these case files are built

  • Every fact comes from a public record or a published news report, linked in the Sources section at the bottom of each page.
  • Money figures are a snapshot as of the date on the page. When newer numbers come out, they are added next to the old ones with a date, so you can see what changed.
  • Each page shows when it was posted and when it was last updated, and lists the updates found since it was posted.
  • Long case files are split into parts, with Next and Back buttons, so each one is easy to read on a phone.
  • Status labels: Documented means the main facts are confirmed in records. Pending means a decision or record is still outstanding. Disputed means a key fact is contested.
